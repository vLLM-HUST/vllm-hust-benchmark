## 方法

数据集 revision 为 `25ed67db7da8f4591484e764008ff585544f5a30`，覆盖 Olympiad 100题、Research 60题。求解上限16384
token，裁判上限8192
token，temperature=0、seed=17、请求级thinking=false、客户端并发1。使用冻结的Qwen替代裁判与首个完整显式VERDICT提取规则；Research得分不低于7记为成功。未决评分保留在完整分母内，不计作成功。

求解已完成160题。裁判恢复沿用原25条记录并补齐135条；25条原件逐字节相同。独立服务与空编译缓存初始化证据留在私有归档，评分结果复用不等同跨轮缓存复用。
