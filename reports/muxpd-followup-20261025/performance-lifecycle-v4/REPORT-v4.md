# MuxPD TP4 性能与生命周期证据追加 v4

本批固定接纳 **12 项终态运行**：五项生命周期实验、六项完整主性能矩阵，以及默认原生参考 v1 在计时前的一次失败。另有一个显式 support 包。既有
v1/v2/v3、原20块套件失败与所有冻结协议保持原字节；后续新运行不自动进入本批。

**当前测得的价值与代价均有限定范围。** 分组 P 比 raw
插件的混合负载平均吞吐提高3.466%，两对分别提高5.913%和1.047%；并未超过本批同步原生参考。最大seed暂停在补充分析中明显缩短，但长P TTFT、seed gap
P99及吞吐有相应代价。完整表格、漂移和跨模式token差异见下文。实际默认原生参考、算子profiler及成对任务质量仍待完成，不能宣称插件普遍胜过原版vLLM，或已通过质量验收。

五项生命周期实验补齐了明确边界内的 P8 取消、ACK前持块/ACK后释放/物理块复用，以及真实 D 抢占期间pending
P持块的观察。这是有限请求/块所有权与关闭证据，不是任意设备竞态的证明，也不是吞吐结果。

## 默认原生参考 v1：保留计时前失败

`perf-native-default-backend-01`实际exit1、controller
FAIL、shutdown返回，**0个warmup/测量窗口**。三个时点的首个只读RPC收到Core
WorkerWrapperBase，v1误把外层wrapper类当作真实NPUWorker类，触发readback校验失败；这不是吞吐或模型质量失败，也没有可用性能值。
