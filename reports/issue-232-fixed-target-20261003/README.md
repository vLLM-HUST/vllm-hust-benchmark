## Hard constraints

The matched pair measures throughput ratio, mean TTFT/TPOT reduction, and raw
P95 latency inputs. It does **not** measure single-chip effective utilization,
unit token cost, or multi-tenant utilization because the run did not collect
the required denominators or time-series telemetry. Those fields remain
`null` with status `not-measured`; they are not threshold failures and are not
reported as passes.

The current pair does not meet the 2x throughput portion of the typical-scene
target (1.021133x). This is a measured threshold failure, distinct from the
three unknown inputs above.
