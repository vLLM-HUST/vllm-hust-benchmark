# 修订版 R10 并行候选筛选（2026-11-25）

范围为 Qwen3.5-35B-A3B BF16 TP2 的一侧实际几何，Ascend 910B2，源自 2026.11.24.10。各组件对照保留构造输入、配对原始计时、实际配置和停止理由。

## FIA V2 同掩码分页注意力

保持 BF16 TND、右下因果掩码、Q=3 MTP2 和同一页布局。切换引入 V2 API。动态图测试更换长度及块页表。每档 7 轮交替，每轮 24 次。

## GMM1 密集累积终点

仅将第一段 GMM 的 256 槽 INT64 分组计数换成累积终点，保持专家顺序和第二段 GMM。覆盖冻结图的 3、6、12、24、40 行及三种固定合成专家分布，尚无真实专家分布证据。

15 档共核对 34,485,480 个中间和输出元素，全部逐位一致。预先构造终点时，11 档的首段中位数较快，最多省 2.11 μs。计入实际图内累积求和后，15 档中的 180
对完整组件均变慢，每次多用 28.66–34.31 μs，止于组件。

接口的 tuning_config 参数缺少 Atlas A2/A3 支持，属于独立的准入检查。

## 调度形状元数据复用

连续调度波次的有序 token 数向量相同时，复用请求索引、相对查询位置及调度 token 数。独立验证包含同总长异分区、缓存失效和重新进入。CPU 6,526 组和 910B2 120
组差分逐位一致。五档每档 13 个配对均更快，稳态每波（含主机提交和设备完成）约省 166 μs。

新版原生十题两 rank 各有 2,873 次目标图回放，2,862 次相邻回放的图桶相同。按相同图桶都命中且组件耗时全部转化为服务收益计算，服务窗口估计上界约 0.69%（配对最大观测约
0.75%）。原始日志缺少有序调度向量，因此该比例只表示机会估算。

[结构化数据与计时清单](summary.json)。独立前置/组件实验和正式模型成绩分别归档。

## ND 分页 KV 写入接口

新版 R10 的原生 ND 写入使用 INT64 槽位。替代接口在 910B2 的算子准入要求 INT32，直接替换在 setup 阶段退出，未计时。

适配 INT32 后，单写入组件在常规执行下快 25.4%–26.8%（含转换）。单写入图回放的耗时变化为 −0.38% 到 +1.19%。十个不同层的写入组合到同一个图后，每图一次转换的 24
行耗时从 288.47 μs 降到 285.48 μs，3072 行从 316.79 μs 降到 289.14 μs。两档均覆盖更换槽位和负槽位 padding，逐层缓存全部逐位一致。

新版原生十题的 3072 图命中为零。将所测 24 行差值投影到该窗口，假定全部 653 次图回放都经过对应写入且收益完全转化，约占 0.0028%。历史同 runner 的上下文窗口按两档计算约占
0.0039%。归档保留 222 个计时组以及算子准入拒绝原件的摘录。本候选止于组件。
