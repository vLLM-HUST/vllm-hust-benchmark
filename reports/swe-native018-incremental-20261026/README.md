## 证据与复算

- `summary.json`：仅聚合结果和受限原件哈希。
- `independent-review.json`：原始轨迹、提交来源、评分链的独立复核投影。
- `release-receipt.json`：模型释放、CPU封存及r2/r3准入映射。
- `cached-summary.json`：后续45次调用任务的独立记录。
- `cached-independent-review.json`：原始/去重测试计数、F2P/P2P、初态与补丁输入独立复核。
- `cached-release-receipt.json`：后续任务12份模型封存文件及CPU封存清单的验证回执。
- `catalog.json`与`derive_catalog.py`：三项不同任务的可复算目录，不遗漏评分限制。
- `verify.py`：无网络、设备或第三方依赖的公开包一致性验证。
- `derive_private.py`：私有环境复算入口；需要原任务输出及源码，不宣称公开包可独立重现私有评分。

受限原件位于已授权CPU持久卷的`runs/swe018-first-missing-r3`，包括原补丁、轨迹、官方评分输出及52文件SHA清单。公开包不包含私有题目、回答、补丁内容、密钥或模型凭据。
