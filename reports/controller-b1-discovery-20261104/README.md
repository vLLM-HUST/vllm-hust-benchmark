## 配置与边界

相同 Qwen3.5-35B-A3B、BF16、TP2、双卡 910B2，执行席位 24、每 rank device State 20 GiB / host State 4 GiB、MTP
2。B/C/D 共享支持跨轮缓存的必要引擎适配。Controller 由 RIDE 管理为独立 CPU 进程，原版调度保留，共同 token-ID
HTTP、容量与无业务超时适配单列；不称未修改的上游二进制。模型由已有外部 Manager 运行，不称完整 RIDE/Ray 模型产品资格。

执行顺序 B→C→D→A，每组只有一次；尚无独立重复或未见输入留出，accepted_pairs=0、validated_win=false。每组实际输出 43,516 token、逻辑输入
5,992,408 token；输出等长不等于内容或质量相等。暖机与业务分开，全部业务完成及释放核验；业务无超时（-1），资源收尾另有截止。正常业务无错误不代表 SDK 收尾无告警。

严格缓存/冷路径逐 token 诊断仍失败（64 个 token 仅 15 个相同），原因未区分为数值路径差异或状态问题。当前性能记录不证明数值等价或任务正确率，不能宣称可无条件部署。非流式回放未测
TTFT/TPOT，字段保留 null，不能借用历史值。A 实际使用 R14 模型/R15 回放，前置导入和命令失败保留，预热到业务间有修复间隔。
