# SWE-smith-tranjactory：离线整批同时到达的短窗口对照

目标：验证整批 Agent program 到达后，request-throttling-controller 能否通过准入、暂停与恢复避免 KV 压力导致的抢占，提高真实模型输出吞吐。

| 配置维度    | 冻结值                                                                    |
| ----------- | ------------------------------------------------------------------------- |
| 模型与设备  | Qwen3.5-35B-A3B / BF16 / Ascend 910B2 / 单个 TP2 后端                     |
| 到达方式    | 96 条完整输入 program 在 time0 同时到达；客户端不设并发上限               |
| 输入        | 2318 轮；历史兼容输入仅将 arrival_time 归零，保留轮次、输出长度和工具等待 |
| 输入 SHA256 | 0d95fa124751067178645e561e5ec99b9442908242ded8da680c383f8bbdc256          |
| 引擎配置    | APC 开启；KV 配置512MiB；max_model_len16384；max_num_seqs16               |
| Controller  | 审计容量49152、每program buffer14335、周期0.5秒；复用固定官方核心与部署   |
| 测量        | seed11；每侧180秒；r15 OFF→ON，r16 ON→OFF；每侧分别重置 prefix cache      |

| 运行 | OFF 输出 tokens/s | ON 输出 tokens/s |  ON/OFF | OFF/ON 完成调用 | OFF/ON 抢占 |
| ---- | ----------------: | ---------------: | ------: | --------------: | ----------: |
| r15  |           15.6576 |          27.7241 | 1.7706x |           48/72 |       246/0 |
| r16  |           15.7807 |          28.3378 | 1.7957x |           48/83 |       249/0 |

结论：两种执行顺序均出现同方向窗口收益。OFF 的 KV 峰值100%，ON为75%；OFF抢占246/249次，ON均为0。两轮均 Ray SUCCEEDED，独立校验通过；共同完成的5轮
prompt/usage哈希一致，零请求/token/history错误。证据支持在该实验容量配置下，调度保留缓存、避免抢占并提升窗口吞吐。

边界：仅seed11和两个顺序，不是多seed稳定结论；窗口结束主动取消的剩余调用不计完成任务，不能推算完整96条批次耗时下降。该APC/512MiB配置不同于原矩阵配置；不是SWE-bench任务解决率。旧C32结果属于客户端限并发历史场景，不是本离线主实验。

下一步冻结：保持相同输入、模型、源码与180秒窗口，新增seed17（OFF→ON）和seed23（ON→OFF）各一对；客户端仍不限流，保留所有结果。r17/r18尚未启动，不冒充已测。

公开副本各自含SHA256SUMS与独立verify.py；不包含内部地址、凭据和token payload。网站尚未发布，完整批次和原矩阵资格未成立。
