## 方法与适用范围

参考时间采用独立组件计量与源码依赖图聚合，保留原 B1 的 F、T、必要工作量和三个冻结工作组。target 使用明确的 r6 canonical 参考轨迹；draft 使用固定同请求、同 draft
step 的统计路由参考，并经过距离支持、实际组大小及预测占比的验证。它们不声称恢复了 B1 实际运行的逐位专家 ID、hidden 或 KV 状态。

组件模型的验证门槛和支持域是经验条件，不构成整模型误差上界。CPU 新测采用预触碰普通内存的内在操作计量，与旧 pinned/DMA 事务上下文存在差别；两 rank 锚点新/旧中位比约
0.741、0.687，仅披露而未校正。原失败计量完整保留；仅 rank0 的 4 行 concat 点按事前冻结的更长 graph 批次修复精度，其余 11 个域模型不变。

本包身份是实际 B1 开发运行栈。官方 vLLM 0.18 + vLLM-Ascend 0.18 的 B0 另有新授权，仍待补齐；本包不表示 B0 已完成，也不表示报告、网站发布已经完成。

## 重建

运行 `python package.py`，从 `package-inputs.json` 固定的来源复制紧凑证据；原路径不可访问时使用本目录中 SHA
一致的副本。生成器仅写本目录，不运行计量、不拟合、不上传、不提交。

归档完成后可运行
`python package.py --archive-manifest /实际路径/manifest.json --archive-readback /实际路径/readback.json`，原样记录私有完整包回执并刷新摘要索引及校验清单。该回执不授予公开权限；公开包须另外按明确的文件和字段白名单制作并审查，不得把本索引替换成私有包的下载链接。`sha256sum -c SHA256SUMS`
可验证本目录。

公开包完成后使用 `--public-manifest /实际路径/public-manifest.json --public-readback /实际路径/public-readback.json`
更新单独的公开索引。生成器核验公开包来源身份、成员回读与公开 DAG 复算结果，再更新索引；不会把私有完整包标记为公开包。

约 1.7 GB 的查询文件、约 13 MB 的 closure 及完整原始数据留在归档中，不复制进入 Git。
