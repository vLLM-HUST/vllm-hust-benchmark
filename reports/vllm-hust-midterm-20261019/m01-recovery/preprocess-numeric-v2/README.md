# GDN 预处理数值验证

## 对象与方法

Qwen3.5-35B-A3B r19 固定版本 GDN 预处理算子，Ascend 910B2，BF16 输入及 Q/K/V/beta 输出、FP32 G 输出。独立 CPU 参考按 FP32
计算并保留 BF16 舍入边界。

测试 1、16、17、72、257 行和两种 Q 布局，共 10 组配置；输入包含零向量、重复映射、非整块尾部及 softplus 分支。阈值在运行前固定：Q/K/beta
rtol=0.016、atol=0.001；G rtol=atol=0.00002；V 完全一致。

## 结果

全部 10 组通过。最大绝对误差：Q 0.00048828125，K 0.000244140625，V 0，G 0.00000095367431640625，beta 0。保存后复算 3 项测试通过。

第一次尝试未加载 r19 的 Triton 兼容启动配置，退出码 1；第二次使用哈希校验后的相同兼容配置，退出码
0。两次均使用独立进程、输出和运行时缓存目录，结束后四卡释放。未加载模型权重或前轮推理状态。

## 结论与限制

验证固定源码在真实设备上的有界数值行为。不代表历史设备映射内容、全模型正确率、图回放或全部跨流依赖已验证；不改变 B0/B1，也不据此计算完整有效 F 或 M01 达成率。

## 证据与恢复

`archive.json` 包含 9 个顺序分片和 114 个常规文件的长度及
SHA256。先逐片校验，再按清单顺序拼接，校验整体压缩流；解包时拒绝绝对路径、路径穿越、重复成员、链接及覆盖既有文件，并逐文件校验。完整压缩流为 7696194 字节。

归档保留两轮日志及回执、设备状态、源码及兼容加载器、编译产物、输入/设备输出/参考张量和 pytest XML。`numeric-tensors.pt` 仅包含 CPU 张量和基础容器；复算使用
`torch.load(..., map_location='cpu', weights_only=True)`。归档内 `test_preprocess_numeric_probe_v1.py`
可在具备 PyTorch 的环境按原目录恢复后复算；仓库测试另外验证归档完整性、来源及记录边界，不依赖 NPU。
