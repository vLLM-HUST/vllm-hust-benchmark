# M01 同工况参考补测与汇总

## 测试对象与配置

Qwen3.5-35B-A3B BF16，Ascend 910B2，TP2，原 MMLU-Pro 200 请求计量运行 worker-r1
的实际形状与序列分区。参考测试独立运行，使用空编译缓存；计算使用两卡、预约四卡。 本目录保存组件参考与硬件计数器审计，不替换正式 B1 服务性能记录。

## 方法与结果

| 参考项     | 每卡覆盖                             | 校验及重复                                              |
| ---------- | ------------------------------------ | ------------------------------------------------------- |
| GDN 递归   | 872 种组合、26,520 次层调用          | 有效输出及状态池 CPU 对照；三次计时                     |
| WY/KKT     | 135 种组合、4,230 次层调用           | W/U 与累计门控 CPU 对照；三次计时                       |
| 卷积       | 1,013 种组合、30,750 次层调用        | 输出及 36 槽状态池 CPU 对照；三次计时，状态误差为零     |
| HBM        | 双卡 BF16 流式参考、每输出流 256 MiB | 各三次至少 5 秒；物理计数器全通道覆盖、官方导出交叉核对 |
| 通信       | 原模型与参考使用同一累计 flit 接口   | 仅累计 TX；三次参考，不依赖 getter 字节换算             |

各运行退出与资源释放记录见原始归档。WY 首次运行在导入阶段失败，未产生计时；修正独立探针初始化后的运行通过，首次记录保留。

## 结论与限制

本批参考补测完成。原始 worker-r1 已包含设备最终预处理映射，新增审核确认其与有效行算量一致， 不再将映射缺失列为补采项。十类源码语义基本运算小计仍为
1,901,558,663,879,214。

完整有效算量定义、融合参考不重叠及最终资源模型判定尚待统一复核，本目录不赋值总体 M01 达成率。 全设备同步窗口为 186.802958029 秒，包含客户端启动及控制开销；原请求窗口约
135.34 秒， 不得混用两种窗口的分子与分母。特殊函数、填充、复制以及各组件的数值覆盖限制继续保留。
