# M01 同步计时轮次的离线算量分析

## 对象与方法

本目录关联 [200 请求同步计时原始证据](../boundary-measured-20261023/README.md)， 受测对象为 Qwen3.5-35B-A3B、BF16、TP2 的
vLLM-HUST 组合优化方案。 输入共 282265 token，输出共 51200 token。实际版本、参数及缓存条件见原始证据。 本目录不改变运行身份，不将开发栈对照标记为官方 0.18
B0。

五个归档分别保存工作量关联、目标矩阵、标量、末层归一化消费者及 GDN 分块分析。 归档保留原字节；manifest 列出归档及全部成员 SHA256。
脚本中的绝对路径是原分析环境的来源定位，不是部署配置。 归档不是独立运行环境；依赖源码由各派生 JSON 的来源哈希标识。

FLOPs 的敏感性差额；实际未作这一扣减。

## 结论与证据限制

本轮计时已测，完整有效算量 F、匹配的独立参考时间和 M01 效率仍未闭合。 尚需关联实际 GDN 分块及初始状态、有效草稿上下文和阶段依赖参考。 本目录不计算 TFLOPS
或效率，不作达标判定，不修改原始结果。

局部算术测试覆盖请求可加性、非法长度拒绝、草稿界限枚举及 GDN 小长度全部 分块枚举。仓库测试另校验归档身份、与原始请求长度的关联及分项加总。 这些测试不代替真实运行路径、完整算量或参考时间的验收。
