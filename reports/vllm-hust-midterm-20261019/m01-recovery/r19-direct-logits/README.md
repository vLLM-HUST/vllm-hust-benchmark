# r19 词表设备计时与请求尾部

## 测试对象与配置

Qwen3.5-35B-A3B，BF16/TP2，Ascend 910B2，同一 MMLU-Pro 200 条输入，out256、无限到达率、E24/R36、KV recompute、FA
Microflow、MTP2、FULL 图模式。 该采集用于 M01 计量诊断，不替换正式 B1 性能或质量结果。

新服务、worker、输出及运行缓存目录；已有目录拒绝启动。固定编译种子逐文件校验，不导入前轮 KV、Mamba 或请求状态。 额外推理预热请求为
0；启动内核预热和图捕获单列，不宣称完全冷编译。四卡独占准入，两卡计算，退出后四卡释放。

## 方法

target logits 记录当前流起止事件、调用前后 stream 标识、主机时间和输入行数；每次调用不执行设备同步。 请求结束后统一同步并导出，核验事件完成、调用正常返回、stream
标识一致和事件顺序。小型 NPU 线性投影资格测试先行通过。 draft 使用合并前向事件及 replay 行映射。设备到主机区间采用 ±2 毫秒容差。

## 结果

200 请求成功、0 失败，输入 282265 token、输出 51200 token。 每 rank 876 次 target logits 调用、1752 个前向包络、2628 个 FIA
发布和 876 个 GDN 最终设备发布。

| 投影         | 每 rank 请求窗口行数 | 每 rank 末响应后行数 |
| ------------ | -------------------: | -------------------: |
| target       |                57433 |                    3 |
| draft step 0 |                19291 |                    1 |
| draft step 1 |                19291 |                    1 |

每 rank 权重形状 `[124160, 2048]`，按 2MNK 计数且 TP 分区只计一次。 窗口词表投影小计 97658653900800 次语义 FLOP，窗口外 5085593600
次另列。 完整 request-to-response、request-to-last-forward、request-to-all-export 三段 HBM/HCCS 覆盖均通过。
原始字节数、积分上下界及设备记录保留于 JSON 和归档。

## 结论与范围

直接事件补充了 target logits 的当前流计时，识别了不能纳入请求窗口的尾部计算。 这些事件不是每个底层算子的独立计时；跨流依赖覆盖仍需结合实际实现核验。 投影账本不含 gather、采样或
argmax；全模型有效 F 和 M01 达成率保持 null。 HBM 含观察器流量，全部导出区间含等待，不作为纯模型执行时长。

## 证据恢复

`archive.json` 包含 32 个分片、完整压缩流及 312 个成员的 SHA256 与长度。 按清单顺序连接分片即可恢复归档；成员均为安全相对路径，保存原运行目录结构。
内容包括原始请求、服务日志、设备记录、退出回执、硬件 SQLite、隔离计划、资格测试、采集源码、派生程序和测试记录。 所有独立 JSON
副本与归档内原件逐字节一致。超过单文件大小限制的加载清单仅保存在归档内。 仓库测试核验归档、运行与源码身份，重算 logits 行数和尾部扣除，并从原始 HBM/HCCS 样本复算区间流量。
