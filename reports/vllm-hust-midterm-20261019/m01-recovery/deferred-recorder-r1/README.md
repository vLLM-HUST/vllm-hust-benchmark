# 延迟读回采集器资格测试

双卡独立图重放测试验证设备端启停采集、target/draft 调用顺序、 容量溢出保护和设备事件时间与主机时间边界的一致性。 每组重放期间不执行显式同步或设备到主机读回，结束后统一校验。

两张卡均通过：启用区间记录 target 6 次、draft 12 次。 容量不足时保留前缀记录，计数继续递增，边界哨兵保持不变。 此类溢出轨迹必须拒绝用于整模型计量。

该测试不是整模型实测，不证明生产模型全部执行流覆盖， 不构成性能提升或 M01 有效算力达标证据。 原始记录、预先冻结的计划、源代码、资源释放记录及独立审计器
均保存在本目录的归档中；`summary.json` 给出校验结论。
