# 实际FIA设备长度补采

本目录保存r13失败采集、设备记录器独立资格测试及r14成功补采的原始证据。 `archive.json`记录分片、拼接压缩包和每个成员的SHA256；原始文件未改写。

- `microflow-token-accounting-r13/`：200请求完成，但标准图参数钩子未覆盖实际FIA，不能用于注意力算量验收。
- `qualification/`：双卡、双执行流、双缓冲及溢出检查，验证设备长度延迟读回。
- `microflow-token-accounting-r14/`：实际owned-FIA发布长度、主机事件、请求结果、退出和设备释放证据。
- `system/`：两轮独立系统采样及原始HBM数据。采样成功不自动代表所有分析区间已验收。
- `source/`：固定运行源码、独立审计、逻辑因果对数核算及缓存隔离要求。

运行`pytest tests/test_midterm_owned_fia.py`可验证归档哈希，确认r13失败边界， 核对r14双rank发布与设备长度序列，并从原始长度复算因果对数。
完整模型有效算量和M01达成率仍为空；不以观察器吞吐替换正式B1。 历史r9/r12主机规划长度不得标为已验证设备实际长度。
