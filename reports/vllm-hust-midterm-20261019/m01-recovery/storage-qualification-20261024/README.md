# M01 迁移后诊断资格测试

## 测试对象与配置

Qwen3.5-35B-A3B，MMLU-Pro 固定 200 请求，BF16、TP2，物理 NPU 3、6 对应容器运行时设备 0、1。运行标识为
`capture-b1-storage-r3`。采用开发运行栈及主机进度源保护诊断候选，完整版本、配置和源码哈希见归档内的 `execution-plan.json`。本轮不属于官方 vLLM
0.18 / vLLM-Ascend 0.18 B0，也不替换已发布的最优 B1 性能结果。

## 方法

迁移后的源码路径按真实路径归一化，保留原有内容哈希校验。服务、输出目录和编译缓存独立创建；缓存初始状态见 `compiler-cache-initialization.json`，启动参数见
`launch-command.json`。共享只读权重和运行库不属于轮次编译缓存。诊断插桩记录调度、草稿及控制动作，结束后导出 worker 记录，排空请求并退出服务。

原始记录中的 155 条未更新事件保持不变。派生主机核对将其分为首次输出前 22 条、输出预算完成后 133 条，无未分类项；200 个请求各保留 256 个输出
token。该分类不等于设备有效算量分类，首次输出前仍可能含有效预填充计算。

KV materialization 的 200 条准入及策略记录均为 `recompute`，复用 token 为 0。Microflow 每个 rank 有 1742 次
`graph_replay`。这些记录证明相应控制路径执行，不单独证明性能收益。

## 结论与证据

请求与诊断采集链路通过资格核验。设备草稿流顺序、位置与写入槽位一致性，以及有效 F 和独立参考时间仍在核验。M01 的
C、C参、η及达标结论均未判定；本轮插桩耗时不作为正式性能结果，也不与其他轮次的算量或耗时拼接。

原始证据归档及独立审计归档的外层 SHA256 见 `archive.json`；原始归档内保留 `SHA256SUMS`。审计归档中的 `storage-r3-final-audit.json`
为单独派生核对，不覆盖原始回执或未分类标记。
