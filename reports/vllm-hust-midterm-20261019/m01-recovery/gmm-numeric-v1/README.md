# MoE GMM 数值验证

## 对象与方法

Qwen3.5-35B-A3B r19 路由记录分为 29 个角色/填充长度分层，按专家行数平方和预选最小、下中位数、最大代表分布，每个 rank 共 83 个代表样本。选择不依赖计时。

本轮取 target 填充长度 3、4096 的最大不均衡分布，使用完整 256 个专家和 BF16 合成权重。GMM1 K/N=2048/512，GMM2 K/N=256/2048；两张 910B2
顺序执行，共 8 个用例。算子参数 group_list_type=1、group_type=0、split_item=2。

对每个非空专家的首尾行进行 CPU FP32 独立矩阵乘法并舍入 BF16，分别抽检 18/24、469/32768 行。容差预设为 rtol=atol=0.02。

## 结果与限制

8 个用例通过，最大绝对误差 0.0078125，全部输出有限。权重格式 ND，stride 连续。独立进程及缓存/输出目录，结束后四卡空闲。路由选择和证据复核共 10 项测试通过。

这是新探针的有界数值验证，不是历史模型布局确认、全输出逐元素验证、TP2 并发容量、模型准确率或 M01 达标结论。源码审计单独标明未被历史回执锁定的文件，保留设备格式和 stride 缺口。

## 证据

`archive.json` 列出 27 个文件、10 个有序分片、整体 SHA256，以及两个仍保留在 r19 原始证据中的外部来源。压缩流为 8234282
字节；逐片校验后拼接并核验整体哈希。解包前拒绝绝对路径、路径穿越、重复成员和链接，逐文件核验清单。

归档含原始日志、设备检查、运行回执、数值抽样张量、源码、路由代表表及测试 XML。张量复核使用
`torch.load(..., map_location='cpu', weights_only=True)`；固定种子和生成源码用于重新生成合成输入，不复用推理结果。
