## 对象与方法

Qwen3.5-35B-A3B，BF16，TP2；MMLU-Pro 200请求，每请求固定输出256 token。运行标识为
timing-b1-storage-r1。采用BetterScale、Prefill Microflow、KV materialization及位置/因果读取修正组合；不作为官方0.18/0.18
B0，不自动替换既有最佳B1吞吐或质量结果。

使用全新服务、缓存和输出目录。开启原生逐请求MTP2接纳统计和CPU侧GDN
prefill聚合计数，未启用设备journal、路由记录或模型profiler。计数、请求期编译和同步成本全部保留，不估算扣减。本轮不是严格无插桩计时。

F为源码语义必要工作量的基础运算计数，矩阵乘法按2MNK、MoE按激活专家计量。特殊函数、比较和除法不赋予任意FLOP等价权重。使用本轮实际接纳序列和prefill聚合计数，排除填充、无输出依赖的草稿及重复工作；不借用r6或历史轮次分子。
