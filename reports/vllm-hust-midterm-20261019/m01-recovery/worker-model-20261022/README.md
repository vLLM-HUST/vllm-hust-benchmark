# M01 双 worker 采集与参考补测

## 测试对象与方法

2026年10月22日，Qwen3.5-35B-A3B，BF16，Ascend 910B2，TP2， E24/R36，上下文上限65536，FULL图，MTP两步，每卡20 GiB KV。
优化组合为KV重计算与FA Microflow。使用同一MMLU-Pro 200请求输入， 新服务进程与独立空缓存目录。此轮为硬件计量诊断，不替换正式B1性能结果。

系统采样与worker性能轨迹分别采集；两个worker均确认采集通道可用后进入测量。 全设备同步边界覆盖请求窗口，边界外包含客户端启动及控制开销。
参考测量使用实际形状、载荷和调用次数，保留三次重复及离散度。 复用既有参考时核对形状及来源，新缺失项单独补采，不按速度挑选来源。

加载模块的路由激活字段确认为SILU；字段确认不等于逐内核分派证明。

## 通信计量限制

实际调用次数加权的三次同步通信参考耗时分别为 41.85436984862281、41.5047984906123、44.18865944058234秒，
标准差1.4591217468192978秒。该分项不是模型关键路径或M01达成率。

驱动带宽getter与累计flit接口的短窗口精确同步未获证明： 2352个方向样本中264个超过对应即时累计增量。 沿用预先固定的整段边界检查，102个含完整getter样本的方向测量段均满足
部分采样量不超过整段累计量，另18个方向段缺少完整样本。 后者不抵消短窗不一致，也不证明完整流量相等；不得混用两个接口的量直接计算达成率。

## 验收结论

本轮完成双worker采集及上述参考覆盖，M01有效算力达成率仍未判定， 不代表已测得低于50%。剩余验收项为GDN递归、WY/KKT及卷积参考，
匹配的HBM带宽参考，完整有效算量归并，以及同口径通信资源界限。 十类算术的基本语义操作小计不冒充完整有效F；特殊函数不任意赋予FLOP权重。
