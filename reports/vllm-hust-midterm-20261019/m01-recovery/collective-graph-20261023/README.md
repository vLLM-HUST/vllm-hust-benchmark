# M01 通信图参考补采

## 测试对象与配置

Qwen3.5-35B-A3B MMLU-Pro B1 轨迹中实际出现的 75 种通信形状，TP2， 参与设备 0、1，独占检查覆盖设备 0、1、6、7。这是独立通信参考测量，
不是一次新的模型吞吐或准确率测试，也不是 0.18/0.18 B0。 实际加载 torch 2.13.0+cpu、torch_npu 2.13.0.rc1；路径和源码哈希见原始计划及各 rank
回执。

## 方法

每种形状保留批量 1、8、32；各批量进行三次重复，每次 16 个样本。 输入在计时外重新初始化，图中不插入逐算子主机同步。记录整图同步墙钟及设备事件耗时， 每个样本在计时后检查完整输出。数值检查包括
all-reduce 和 all-gather 的两个 rank。 采用全新输出及缓存目录，不复用上一实验编译缓存；没有 eager fallback。

## 结果与结论

两卡各完成 10800 个样本，覆盖全部 75 种形状，所有样本数值验证通过。 worker exit 0，会话已退出，四卡释放，原始 SHA 清单和独立成对样本审计通过。
全部批量及重复样本保留，不以最短批量结果选择参考。

本结果补齐通信图参考样本。模型级依赖关系和有效工作次数仍需关联， 不能将通信时间简单加到其他资源时间，也不能直接计算整模型效率。 完整 F、模型参考时间、效率和 M01 达标判定保持未判定。

## 证据

`manifest.json` 记录压缩包及每个原始成员的 SHA256。 压缩包包含原始样本、数值和运行回执、服务日志、设备状态、冻结计划、 SHA 清单、独立审计及此次准入
wrapper。原字节保留在归档中。 本地审计与仓库测试检查双 rank 样本覆盖、数值标记、生命周期和哈希。

准入采用已封存 FS 磁盘失败回执及设备释放证明，未修改原失败记录； 启动前仍重新取得实验锁并三次核对四卡空闲。该策略不将 FS 128/160 改为完成。 归档内 B1
同步计时计划仅为准备材料，不作为已完成的计时证据。
