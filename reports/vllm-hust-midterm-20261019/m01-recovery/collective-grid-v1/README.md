# TP2 通信参考矩阵

## 对象与方法

从已恢复诊断库提取全部 56 种通信组合，保留 BF16/INT64、操作类型、元素数及 TP2 拓扑。双 rank 各 119,098 次诊断调用及 161,361,797,408 bytes
API 输入载荷；不是 r19 调用次数或物理链路字节量。

固定运行时和 Ascend 910B2 上，每种尺寸预热 5 次，3 组重复，每组 512 次。同步计时包含主机发射、同步及 all-reduce 输入恢复开销；同时采集双卡 HCCS
端口计数和独立带宽接口。新进程、输出及可写缓存目录独立，不导入前轮推理状态。

## 结果与边界复核

168 点全部通过双 rank 数值检查。运行与清理退出码为 0，采样器无错误，四卡释放。

原分析 `summary.json` 的起点为首调用前 0.75 秒，距预热和 barrier 完成约 0.25 秒，部分预热计数尚在更新，10/56 种尺寸通过全部重复的边界检查。修正版
`summary-v2.json` 统一将起点设为首调用前 0.25 秒，终点仍为末调用后 0.75 秒。两端 0.1
秒邻域要求稳定；起点邻域必须在预热后、测量前。规则对全部点一致，没有搜索最快平台或逐点选择边界。旧分析和原始记录不变。

修正后 56/56 种尺寸各三次重复均通过计数稳定性与双端收发一致性检查，计数无回退，每种尺寸的三次物理计数完全一致。独立复算 14 项测试通过。各点单列时长及速率中位值、最小值、最大值。

## 限制

结果仅为诊断形状的同步参考，不覆盖 r19 实际通信分布、图回放并发或模型资源重叠；不计算完整 M01 达成率，不替换 B0/B1。flit 速率与 API
输入字节速率不同。原始带宽接口样本保留为独立证据，不将其部分时间覆盖均值当作全区间流量积分。

## 证据恢复

`archive.json` 描述 10 个顺序分片、43 个文件及其长度和 SHA256；完整压缩流 8154877
字节。逐片校验、按顺序拼接并校验整体后，只解包无路径穿越、无重复且不覆盖既有文件的相对常规文件，再核对全部成员哈希。

归档含原始采样、两版分析、测试、源码及两个通信表数据库。数据库是原大型 profiler 数据库中
`COMMUNICATION_OP`、`STRING_IDS`、`ENUM_HCCL_DATA_TYPE`、`RANK_DEVICE_MAP`
的逐行一致副本；完整原库不重复打包，原库哈希及复制过程保存在 `collective-source-tables-v1/provenance.json`。副本足以独立复算全部通信直方图，不代表完整
profiler 数据库。
