# M01 位置校正与草稿读取范围验证

## 对象与方法

Qwen3.5-35B-A3B，BF16、TP2，MMLU-Pro 固定 200 请求，物理设备
3、6。两轮均使用独立服务、全新编译缓存和输出目录；共享只读权重及运行库。完整参数、输入与源码身份见各原始归档中的
`execution-plan.json`、`launch-command.json` 和缓存初始化回执。

两轮采用开发运行栈的诊断候选，不属于官方 vLLM 0.18 / vLLM-Ascend 0.18 B0，也不替代已发布的最优 B1 性能结果。位置阶段记录覆盖每个 rank 前 128
个波次，地址记录另作全程校验。

两轮均在请求及导出完成后受控关闭服务，排空和设备释放已确认。

r4 在校正前的设备端进度输入中发现与主机快照不一致的行，rank 0、1 分别为 580、584 行；RoPE 上传、位置校正公式和后续草稿拷贝与各自捕获的输入一致。

r5 使用独立设备缓冲同步传入受保护的主机进度快照。两 rank 全程地址差异均为 0，前 128 波次的六类阶段比较差异均为 0。同步拷贝是该候选运行路径的一部分，其成本不能从后续实测时间估算扣除。

r5 的第二步草稿仍有独立读取范围偏差：每 rank 的 19347 行中，2389 行多读 1 个位置，1855 行多读 2 个位置，合计 4244
行。差值与首步未选中尾部长度一致。该记录不通过截短原始统计修复，后续候选另行修正读取端点并验证。

## 判定与证据

r4 完成差异定位；r5 通过所述位置与地址检查，但完整草稿读取范围资格尚未通过。两轮诊断耗时均不作为正式 M01
时间，不与其他轮次的算量或耗时拼接。F、参考时间、C、C参、η及正式达标结论均未判定。

各轮目录包含 `archive.json`、`qualification-summary.json` 及原始归档。外层归档哈希和原始清单哈希分别保留，归档内原始 `SHA256SUMS` 覆盖 21
项文件。摘要为派生说明，不修改原始回执。r3 已入库证据见相邻的 `storage-qualification-20261024` 目录。
