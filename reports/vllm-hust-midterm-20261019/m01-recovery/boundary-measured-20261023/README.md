# M01 B1 同步计时补采

## 对象与配置

Qwen3.5-35B-A3B，BF16、TP2，MMLU-Pro 固定 200 请求，输入 282265 tokens， 输出 51200 tokens。B1 为 E24/R36、KV
materialization 与 Prefill Microflow 组合。 vLLM 为 0.28.1.post1.dev143+gf18cf803c 开发栈，Ascend
按冻结源码与实际导入身份记录； 本轮不是 vLLM 0.18 / vllm-ascend 0.18 B0。 服务参数沿用既有 r10，启动命令及源码哈希见归档。

## 方法

新建服务、输出目录和空编译缓存，不导入前一轮缓存。加载及图捕获后执行固定请求。 未开启 profiler 或逐 token 算量观察器；增加请求测量区间两端的双 rank 设备同步， 保留原
benchmark 客户端耗时及包含末端 pause、drain、RPC 的同步包络，不估算扣除开销。 既有 MOD 控制日志保留，启动、预热及测量记录按原范围归档。

## 结果

| 项目                                  | 实测值                     |
| ------------------------------------- | -------------------------- |
| 成功 / 失败请求                       | 200 / 0                    |
| 输入 / 输出 tokens                    | 282265 / 51200             |
| 客户端耗时                            | 120.6243702378124 秒       |
| 同步包络                              | 120.65347687713802 秒      |
| 客户端口径输出吞吐                    | 424.4581745716772 tokens/s |
| Microflow split-prefix 事件           | 每 rank 130                |
| 目标 MTP 图回放事件                   | 每 rank 874                |
| KV request-scoped recompute admission | 200                        |
| KV reused tokens                      | 0                          |

MOD 事件数覆盖服务生命周期，不直接作为请求窗口 FLOPs。 KV 记录证明实际重算/绕过动作，不表示缓存命中收益。 客户端 exit 0，控制器按计划停止服务后进程组已退出、四卡释放。
原始清单、200 请求明细、双 rank 同步、配置及 MOD 控制关联经独立审计通过。

## 结论与证据

本轮取得固定工作量的同步计时和控制证据，尚未闭合有效算量 F 及同工作量参考时间， 不作 M01 达标判定，也不替代任务质量评分。耗时高于既有约 62 秒轮次，差异原因待核对；
不以旧轮次时间替换本轮实测值，不据此直接判定优化方案退化原因。

已确认缓存初始条件存在差异：r10 导入 859 个 Triton/Inductor 编译种子文件， 本轮编译缓存初始为空；r10 原初始化记录见
r10-compiler-cache-initialization.json。 这不等同于复用请求输出或 KV 中间结果，也不足以证明全部耗时差来自编译。
未获得相应证据前不扣除任何时间，不把两轮当作缓存条件完全相同的对照。

原始数据、请求明细、日志、冻结计划、生命周期回执及修正后的独立审计保存在归档中， 逐成员及归档 SHA256 见 manifest.json。原实验记录未修改。
本轮按既定计划执行；后续验收依据项目里程碑大纲 V1.5 第 3.4.1 节核对适用性， 不能仅因文档换版将既有计量结果改标为达标。
