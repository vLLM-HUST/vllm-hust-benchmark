# r17 最终设备状态与同轮计数

本目录保留同一 MMLU-Pro 200 条输入、out256、无限到达、E24/R36 的诊断补采。 原始吞吐包含观察器开销，不替代正式 B1，也不构成完整 M01 达标结论。

## 证据范围

- 每卡 888 次最终 GDN 发布，以及 2,664 组注意力长度、页表和计划。
- 请求原文、输出、时序、服务日志、运行隔离和资源释放记录。
- 八字段设备快照及此前反馈快照的双卡独立资格测试，包含容量溢出负例。
- 请求窗口内的 HBM 原始数据库、HCCS 计数、解码与区间覆盖结果。
- 同轮矩阵、卷积、循环验证及 prefill 语义账本和来源哈希。

每卡 360 个验证 token 的设备槽位为跳过标记，不计入对应状态运算。 主机槽位不能代替最终设备驻留地址或有效行判断。该结论不追溯改写旧运行记录。

请求至末响应及末前向事件区间的 HBM 覆盖完整；全部观察器导出同步区间超过采样终点， 其完整 HBM 字节数为 null。未外推缺失尾部，严格全区间审计源码也保留在归档中。

## 恢复与验证

`archive.json` 记录分片、完整压缩流和每个成员的 SHA256 与字节数。 按索引顺序拼接分片后解包到独立目录，不能覆盖原始环境。 成员名使用原路径去掉首个
`/`；来源哈希中的路径通过解包根目录映射。

从仓库根目录执行：

```bash
pytest -q tests/test_midterm_r17_device_state.py
```

测试从归档重新验证来源及生命周期、设备有效行、组件语义算量、原始 HBM/HCCS 区间和尾部缺口。 算量为源码语义口径，非设备指令计数；指数、SiLU 等单列。 完整有效
F、匹配容量、全部模型流完成边界与 M01 达成率仍未闭合。
