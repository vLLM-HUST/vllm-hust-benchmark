# M01 主机进度缓冲区生命周期验证

## 测试对象与方法

测试对象为固定恢复运行栈上的 pinned CPU 整数缓冲区及 NPU 异步拷贝，不加载模型。 在设备流中排入矩阵计算后，异步上传32个初值为100的整数，随后将原主机缓冲区减1。 未保护源与独立
pinned 快照各执行3次；双缓冲候选连续执行6次，复用前等待对应流事件。 运行前取得容器及四卡协作锁，连续3次确认空闲，运行后检查设备释放。

## 结果

| 条件             | 次数 | 结果                                      |
| ---------------- | ---: | ----------------------------------------- |
| 未保护源         |    3 | 每次32个值均为后续修改值99                |
| 独立 pinned 快照 |    3 | 每次32个值均保持预期值100                 |
| 双缓冲保护候选   |    6 | 每次32个值分别保持100、99、98、97、96、95 |

子进程退出码0，四卡释放；原始文件SHA256校验通过。 候选在正常返回、异常、缓冲区复用及重入条件下的CPU测试原件另行保留。

## 结论与范围

本探针复现了异步上传读取可变主机源的风险，并验证了当前流事件约束下的双缓冲保护。 它不证明旧整模型运行实际发生了相同DMA时序，不证明r6位置差异已修复，也不提供完整F、参考时间或M01达标结论。

整模型集成是独立诊断候选：默认关闭，显式启用时记录实现标识和两卡实际prepare调用计数。 随附r11冻结计划尚未执行，不是新的B1性能结果。旧轨迹与原始数值不改写。
