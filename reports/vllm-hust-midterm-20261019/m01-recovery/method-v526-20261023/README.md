# M01 V5.26 方法与既有证据复核

## 测试对象与方法

测试对象为 Qwen3.5-35B-A3B 的既有 MMLU-Pro 200 请求工况。 当前性能 B1 为已实测的 E24/R36、KV materialization 与 FA Microflow
组合。 本目录为方法及证据复核，不新增 B1 性能成绩或 M01 达标结论。

依据《vLLM-HUST 中期测试大纲》V5.26，文件 SHA256：
`e3726dc18554d7cb2ead94dc70a6881f9b8709563af1a9eb7446795ccbe0100f`。

- 单芯片平均有效算力：`C = F / (k * T * 10^12)`，单位 TFLOPS。
- 同工况可实现效率：`eta = T_reference / T * 100%`，验收门槛为 50%。
- `k` 为全部实际参与芯片数，本轮 TP2 为 2；成本统计的预留卡数另列。
- 有效 `F` 不计填充、重复计算、未采纳草稿和缓存省略的工作。
- 正式 `T` 使用加载、预热后的无插桩同步墙钟；不估算扣除插桩开销。
- 参考时间由独立标定、必要工作量、阶段依赖和资源重叠推导，不以资源总时间最大值代替依赖，也不以 B1 实测时间反向拟合。

B0 固定为 vLLM 0.18 / vLLM-Ascend 0.18。B1 可采用不同基座及实现配置， 包括量化、推测解码、缓存、图模式、算子、批处理、调度和逻辑并行等。
比较须保持基础模型及源权重、任务和请求语义、采样输出约束、质量/SLO、 统计规则及物理资源可比；质量和性能绑定实际受测配置。
两侧采用同一参考方法，精度、工作量或路径不同则分别核算参考时间，条件一致时共用。 不同参考下的效率比不能作为性能提升率。

旧有效行算量包括全部 draft 路径，尚不能直接作为新定义下的有效 `F`。 draft 首步还包含隐藏状态处理，注意力工作量依赖上下文，不能将整体算量统一乘以采纳率。

不能直接充当图模式的必要通信关键路径。原计数、物理流量证据和旧资源参考结果保留。

## 补采范围与判定

通信图模式补采清单包含原有全部 75 种形状、每图 1/8/32 次通信、三次重复、 每次 16 个计时样本。输入重置和数值验证位于计时外，记录同步墙钟及设备时间，
保留全部批次结果，不按最高效率择取批次。

清单当前仅通过离线检查，尚无该清单的 NPU 实测结果。 有效工作量映射、正式计时边界、独立参考及依赖适用性完成前， 新 `F`、参考时间、效率与达标判定均为空。原约 30.25%
的插桩资源最大值结果 按原方法单列，不改写为新口径成绩。
