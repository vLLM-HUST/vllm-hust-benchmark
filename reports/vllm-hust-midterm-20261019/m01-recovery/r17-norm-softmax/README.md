未重新运行模型，未混入其他轮次的 token 数或缓存结果。

平方根、指数、SiLU、除法和比较分别记录，不人为折算成乘加 FLOPs。 空尾部单列零值。归一化基于本轮 339835 个 target 有效行及 359236 个 draft 有效行推导，重复的

GDN 状态更新跳过不等价于后续归一化也被跳过，因此本账本不扣减该类行； 也不据此认定每一行均对最终返回结果有效。源码调用路径哈希与本轮加载记录一致，
但加载清单不能证明所有融合归一化二进制的实现与数值等价。 标准 softmax 计数不是融合内核指令数，未计在线分块重缩放和图填充。 完整有效 F、匹配参考能力和 M01 达成率仍未确定。

## 复算

`*.py.txt` 保留实际推导源码和测试的原始字节，避免代码格式化改变原始证据； 恢复时去掉末尾 `.txt`。JSON 中保留源文件 SHA256 与原运行绝对路径用于定位，
这些路径不是可移植安装配置。

`r17-device-state` 中任何原始文件。
