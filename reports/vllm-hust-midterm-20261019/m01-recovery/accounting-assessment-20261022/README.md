# M01 设备窗口经验参考核算

测试对象为 worker-r1 的 Qwen3.5-35B-A3B 同工况插桩运行，200 请求全部成功。采用既有有效行基础运算口径：矩阵乘法按 2MNK，TP 全局语义工作只计一次，GDN
分片求和；特殊函数等排除项保留，不换算为任意 FLOP 权重。

资源参考时间取计算、HBM、通信项最大值，不相加。每项保留全部重复；独立实验的重复编号不强行配对。设备窗口为 186.802958029 秒，经验参考时间为 40.941105 秒，达成率为
21.916733%，未达到内部 50% 阈值。

窗口包含请求前约 49.02 秒和请求后约 2.44 秒开销。该结果不代表未插桩请求阶段达成率，不替换正式 B1 吞吐。HBM 物理读写比偏差约
3.6%，合计与分方向项均保留；此偏差不改变当前最大资源项为通信项的结果。分量极值组合仅作敏感性范围，不是置信区间。

为本次核算；[composition.json](composition.json) 和 [window.json](window.json) 保留此前独立复核状态。大文件及原始轨迹沿用
