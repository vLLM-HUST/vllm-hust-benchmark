# M01 整链参考测量实施细则 R1

## 测试对象与范围

Qwen3.5-35B-A3B，BF16，Ascend 910B2，双芯片 TP2，固定 MMLU-Pro C200 与匹配 H200。B0 为官方 vLLM 0.18 / vLLM-Ascend
0.18。B1 为当前纠正实现的 vLLM-HUST 优化组合。参考实现为恢复修正版 E24/R36 + KV，关闭 Microflow；各运行分别记录实际源码、二进制、配置与资源身份。

本细则于新批次测量前冻结，作为项目实施要求，不替代原指南或第三方批准。冻结参数见同目录 `m01-wholechain-acceptance-r1.json`。本批计时保留必要 CPU
计数及修正成本，不称为严格无插桩测量。

## 参考与计算

参考为指定工况下独立运行标定的经验整链能力，不是芯片理论峰值或已证明的全局上限。官方 B0 仅为对照，不作为参考分母。

每窗 `C = F / (2 × T × 10^12)`，F 与同步时间 T 必须来自同一窗。三次独立 C200 校准的 C 中位数为 C参。共同参考适用时，分别计算
`T参_i = F_i / (2 × C参 × 10^12)`、`η_i = 100 × C_i / C参 = 100 × T参_i / T_i`。C、C参单位为
TFLOPS/芯片，T、T参单位为秒。

本实施口径的目标为 η ≥ 90%。不截断超过 100% 的值，不通过调整分母、扣除假定开销或选择最快重复获得达标结果。原已闭合 F/T/C 与本批参考标定分别保留来源；C 提升率不称为 η。

## 判定规则

- 质量：两份新质量窗使用既有同一 C200 质量合同、评分器、模板、采样规则及 EOS；各自正确数不少于 151/200，失败请求为
  0。该门槛不允许固定子集点估计下降，不代表统计非劣证明或全量数据集结论。相邻源码成绩不能转移。
- 时延：没有既定绝对时延 SLO，不作绝对时延达标声明。如实报告可观测时延分布；无法观测的逐 token 时戳或分位数保留缺失，不以均值代替。
- 重复稳定性：三次有效校准的 `(最大 C − 最小 C) / 中位数 C ≤ 5%`。5% 是约束参考重复波动的工程门槛，不是统计置信区间。
- H/C 性能适用性：`abs(C_H / C参 − 1) ≤ 10%`。该阈值允许匹配样本间有限语义变化，但不单凭算力接近判定工作量等效。
- 工作量适用性：保留类别数及输入长度箱匹配。以三窗 C 的总账合并计算必要 prefill/decode FLOPs 份额及每实际输出 token 的有效 FLOPs。H、B0、B1
  各自与校准总账比较：对应份额差不超过 5 个百分点，单位输出有效 FLOPs 相对偏差不超过 5%。分项必须与原有效 F
  精确守恒，不能重新纳入被排除的填充、冗余或未采纳草稿工作。共同参考不适用时保留 own C，不作共同 η 达标判断。

上述阈值均含边界。质量采用不下降原则；重复与独立样本阈值分别限制运行噪声与工作量迁移，不依据本批测量结果反向调整。

## 执行与停止

每窗独立服务、结果目录和六类新缓存；共享只读权重不等于复用前窗状态。独占租约、设备映射与归属、端口、空间、实际 import、图捕获、hook
和计量生效验证纳入执行清单；第一获准窗完成运行验证，不另增资格探针。

每窗仅一次尝试。启动期限 3600 秒，性能客户端期限 1800 秒，质量客户端期限 7200 秒；期限为执行安全限制，不是服务时延 SLO。租约须覆盖对应期限及 drain。

任一质量不达标、运行失败、源码偏移、计量缺失、抢占或资源/缓存污染，停止后续窗口。慢但有效的结果完整保留；稳定性或适用性未通过，不以换窗择优。保留所有请求、异常、计量、窗口和 drain
边界及资源释放证据。

任何后续重试或口径变更须另立事前版本并保留原始失败；不得为获得 90% 调整规则。精确执行清单独立复核通过后，才能启动对应窗口。
