Raw `vllm bench serve` result JSON (36 fields: per-request latencies[],
p99 TTFT/TPOT/ITL, failed, duration, date, model_id, ...).

These files are copied byte-for-byte except for one normalisation: a trailing
newline is appended when the source JSON lacked one, as required by the
repository's end-of-file hook. No other byte is changed, and every file is
covered by SHA256SUMS-v1.
The aggregate numbers quoted in REPORT-v1.md come from the driver's
`results.json` (archived one level up as `abba-*.json`), not from these files.
