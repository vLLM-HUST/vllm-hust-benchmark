# 9450 上 B1 与 B1 加原版 ThunderAgent 的完整高并发回放

## 实验目标

固定 B1 的 `state_resident_seats=80`，比较直连引擎与在客户端和引擎之间加入原版 ThunderAgent 的完整批次耗时及 KV 缓存命中。

## 配置和对照

9450 的 ascend87 同一双卡工作区，Ascend 910B2 物理卡 5、6，Qwen3.5-35B-A3B，双卡张量并行。引擎为 `full-answer-b1-20261113-r6`
的跨轮缓存变体。两组各自冷启动，完成同一套 71 次预热。两张卡实际均为
`max_num_seqs=24`、`state_resident_seats=80`。两组的运行版本、插件和规范化启动参数匹配。相同的独立 4 核 CPU 工作区运行回放，第二组用 RIDE
local 启动原版 ThunderAgent。实际加载的 17 个文件与固定上游提交逐个匹配。两组使用相同的非流式 token-ID
请求和无业务超时配置。[资源配置](actual-capacity-direct-1.json) · [匹配检查](matched-engine.json) ·
[ThunderAgent 来源](upstream-provenance.json)

## 输入和测量范围

同一份 112 个 SWE-smith 多轮任务、每个任务三轮，所有任务同时到达。同一任务的下一轮保留前轮实际生成的 token 和工具等待。共 336 次请求。回放输入 SHA-256 为
`78e29e2a60ca71f9e87808cdea6277a4d353a6996e034398ea84267c377672a9`。整批耗时是从回放开始到最后任务完成。两组引擎启动和预热耗时另记。

## 完整批次结果

| 指标                              |     直连 B1 | B1 加原版 ThunderAgent |
| --------------------------------- | ----------: | ---------------------: |
| 完成任务                          |   112 / 112 |              112 / 112 |
| 成功请求                          |   336 / 336 |              336 / 336 |
| 整批耗时                          | 338.5452 秒 |            236.7936 秒 |
| 输入 token 中命中 KV 缓存的比例   |      35.20% |                 60.25% |
| 输入 token 中未命中 KV 缓存的数量 |   3,882,829 |              2,382,088 |
| 续轮零命中                        |   106 / 224 |               21 / 224 |
| 运行中采样的 KV 缓存占用峰值      |      99.83% |                 99.83% |
| 请求端到端第 99 百分位耗时        |   296.20 秒 |              209.28 秒 |

整批节省 101.7516 秒，耗时降幅 30.06%。KV 缓存命中率增加 25.04 个百分点。输入 token 总数两组均为 5,992,408，输出 token 总数均为
43,516。[可复算指标](paired-performance-verified.json)

## 实际控制行为

回放期间的运行快照中，25 个 program 处于暂缓放行状态。限流层记录了 336 次请求接收、放行和完成。收尾状态中等待队列为空，两组运行期间的采样峰值均到 99.83%，超过预先规定的 95%
压力阈值。加限流层后命中增加，符合暂缓放行能够减少跨轮状态丢失的预期。未命中 token 按 API 报告的输入 token 和缓存命中 token
相减，未把这个值当作逐内核计算量。[调度快照](controller-client-current.log) ·
[控制事件核算](controller-delivery-event-counts.json) · [压力回执](direct-pressure.json)

## 结论边界

这是一次完整的顺序配对。首轮输入固定，续轮继承各自实际输出，336 个请求中有 170 个实际输入 token 序列逐字一致。只有这一组固定负载的收益证据，独立重复、其他并发条件和真实 Agent
任务解决率尚未测量。两组的引擎规格均为 80，本轮衡量加限流层的增量，后续才能比较不同驻留数下的增量变化。
