基线为 full-answer-b1-20261124-r10 / 2026.11.24.10，设备为 Ascend 910B2。各项保留独立的组件或 CPU
口径。实际工作负载日志用于归因估算。本轮没有候选整模配对或项目 4.1–4.4 结果。

| 候选                | 结果及停止理由                                                                                                                         |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| GDN 3072 双布局 K   | 3072 图组件逐位一致，72.64→40.32 μs，14 对均更快。十题中 3072 图命中为零。32K/C8 每 rank 命中 1,131 次，按零重叠估计节省约整窗 0.35%。 |
| 解码 KV 零新增页    | 15,360 组 CPU 状态和副作用核验。单次节省约 0.96 μs，按每个输出 token 一次命中估计约整窗 0.04%。                                        |
| 共享专家投影合并    | 两个真实 TP 分片在采样层逐位一致。小型图更快，32、40 行回退。同窗按限用小尺寸计算，整窗估计约 0.34%，观测最大值加权约 0.40%。          |
| GEMM＋TP2 AllReduce | 舍入反例和更换输入的重放逐位一致。两 rank 五档共 140 个计时对全部变慢。                                                                |
| 同掩码 BSND         | 四档动态图变化为 −1.44% 至 +0.93%。与独立 FP32 参考的数值核验通过，两个 BF16 布局仍有位差。                                            |
