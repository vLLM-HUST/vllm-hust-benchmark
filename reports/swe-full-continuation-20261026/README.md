# SWE-bench-Pro 全量接续与单题停止原因

## 测试对象与方法

Qwen3.5-35B-A3B，指定B0为vLLM0.18.0 / vLLM-Ascend0.18.0。 输入为冻结V1的731个不同任务，不混入V2或hard子集。既有单题沿用
100步、1200秒、每次最多4096输出token、temperature=0、seed=0、thinking=false、零自动重试。
本次复核只读取已封存轨迹、工具观察及官方评分，不重新请求模型或执行补丁。

## 已测结果

原Agent调用100次、耗时435.975943秒，以LimitsExceeded结束，未主动提交。 100次模型返回均为stop，单次最大输出1281token，未触及4096限制；工具观察完整，
98次返回0，其余两次为查找命令非零返回，无格式拒绝或工具超时。 独立官方评分为0/1、未决0；121项测试中117通过、4失败。

第82、94步的sed替换未转义ampersand，导致源文本重复；第83、95步观察可见， 第87、96步回退后重写。第80、93步只测试模拟逻辑，guest用例仍失败，不能作为
实际集成代码通过的证据。最终官方测试报告`user is not defined`。 证据支持预算内修题失败，不支持执行器故障；不增加步数或选择性重跑。

## 复用与剩余范围

该有效负结果在相同协议全量中按唯一任务复用，指定B0剩余至多730题。原执行器来源锁只覆盖8题NodeBB，其中1题已测。
本次已将全部731题的必要官方文件哈希纳入规范来源锁，原锁定值全部保留；3,681份本地文件与固定官方Git树逐项匹配，新增必要文件哈希2,820项。
其余7题先完成镜像固定、干净任务初态和资源绑定，再执行；另723题继续准备镜像和执行环境。准备顺序不按预期成绩选择任务，不把未准备题从全量分母删除。
其他运行栈、预算、模型或V2结果保留原身份，不能冒充新增指定B0任务。

现有源码与镜像摘要可复用，仍须绑定实际AMD64隔离执行后端；ARM SWE环境不自动覆盖。 最新授权允许在冻结真实必要范围后执行，并非缺少执行授权；后端就绪不等于任务评分通过。
