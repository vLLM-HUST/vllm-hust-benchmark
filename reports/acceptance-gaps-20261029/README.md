## 公开报价及条件成本演算

[天翼云公开价格](https://www.ctyun.cn/document/10029787/10047957)中的双卡 910B 64GB/卡实例为 36,908 元/月， 对应 32
vCPU、256GB 主机内存。[计费说明](https://www.ctyun.cn/document/10029787/10030140)将云盘和公网带宽另计。
本次按用户授权采用类似机器的标价估算，30 天为分析折算假设，不是本机账单或供应商统一月天数规定。

按两侧同占两卡、同费率、已有同步计时窗口演算，成本为 66.2253 → 35.4849 元/百万输出 token，下降 46.4178%。 这是条件演算：B1 两卡已由原始计划核实，B0
计时轮保留卡数尚未回读；不能填写 M06 通过。 原始计时、出处、公式参数与限制见 [成本复算](pricing-and-conditional-cost.json)。
