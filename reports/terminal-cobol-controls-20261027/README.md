# Cobol ARM64 Controls

Fresh nop: 1/3 passed, reward 0. Fresh oracle: 3/3 passed, reward 1. One of each, original tests and
oracle unchanged. These controls alone do not add model coverage.

Run `python3 verify.py` for offline evidence checks. Published whitelist files are exact copies;
restricted original evidence is represented only by its SHA256. No experiment is run by this
verifier.
