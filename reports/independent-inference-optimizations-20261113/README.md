# Independent inference optimization MODs

Three independent public MOD repositories, published on 2026-11-13. Each entry retains its
historical workload, baseline, process-level measurement scope and the separate CPU validation of
the extracted package.

- [Graph Capture Coverage](graph-coverage/README.md): stock vLLM capture configuration.
- [Prefill Admission](prefill-admission/README.md): stock vLLM per-request prefill threshold.
- [SGLang Prepared Dispatch](sglang-prepared-dispatch/README.md): prepared typed FIA dispatch; the
  packaged adapter's separate device requalification remains pending.

These records import the result summaries and protocols already present in the public MOD
repositories. They add no new performance measurements. The owner of all three repositories is 张书豪
(@ShuhaoZhangTony).
