## 当前结论

解码步的整组验证误差约 3.6%，但 native 缓存恢复耗时仍有明显状态变化，通用 TTFT 和尾延迟 精度尚未通过。保留改善条件、退化条件、初始诊断和未完成范围；不能用平均 E2E
接近代替分段正确。
