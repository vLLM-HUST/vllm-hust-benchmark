## 已确认原则

按数类相关 workload 组织一个可安装、可使用、可核验的完整交付批次，不再按单个数据集开
PR。来源级验证与类别级交付状态分别维护；合批不改变验证分母，不抹掉未完成项。科研观测、采集钩子、机制干预及研究分析不属于迁移范围。

每批同时包含读取适配、必要的数据准备和执行入口、安装依赖、使用文档、CPU 正确性 smoke、来源级验证证据，以及研究消费端所需的接口联调。企业原始数据、私有响应、评分参考内容和凭据不进入公开提交。
